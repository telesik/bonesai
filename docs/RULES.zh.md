## 1. 术语

| 术语 | 含义 |
|---|---|
| **先手玩家** | 本局先行的一方。该角色每局重新确定（§2.5）。 |
| **后手玩家** | 本局中先手玩家的对手。 |
| **对子** | 两半点数相同的牌（0-0、1-1、…6-6）。全套共 7 张。 |
| **根牌** | 开启一局的对子。桌上的第一张牌。 |
| **牌堆** | 未发到手中、扣着的备用牌。 |
| **端** | 已摆图形边缘的开放点数，可在其上接下一张牌。 |
| **枝** | 从分叉（或从根牌）到某一端的一串牌。 |
| **分叉** | 枝分成两个方向的地方（§6.3）。 |
| **直向端** | 分叉中保留了被接点数的那个端。 |
| **转向端** | 分叉中由所接牌空余一半形成的端。 |
| **新端** | 分叉中尚未接过任何牌的端（§6.4）。 |
| **封闭端** | 被「横放」的对子封住的端（§7.1）。不能再发展。 |
| **死端** | 无法再接牌的端：带该点数的 7 张牌已全部在桌上。 |
| **直放** | 出牌方式之一：延续枝而不分叉。 |
| **转向** | 出牌方式之一：形成分叉。 |
| **横放** | 对子的出牌方式：封住该端。 |
| **僵局** | 任何人都无法出牌的状态（§9.1）。 |
| **出完** | 玩家打出手中最后一张牌（§9.2）。 |
| **一局**（一轮） | 从根牌到僵局或出完的一次发牌。 |
| **比赛** | 打到 100 分为止的一系列局（§10.5）。 |

## 2. 组件与准备

2.1. 一套普通的标准多米诺骨牌：28 张，双六制。无任何额外组件。

2.2. 游戏为双人。本局先行的一方称为**先手玩家**，其对手称为**后手玩家**。这是一局之内的
角色，不是固定的名号：先行权逐局转移（§2.5），因此下一局双方通常互换角色。

2.3. 每局开始前将全部 28 张牌重新洗混。每名玩家取 **7 张**，牌堆剩 **14 张**。

2.4. 先手玩家的 7 张牌从一开始就**明拿**（正面朝上）。后手玩家**暗拿**，并在行棋权第一次
转移之前保持手牌不公开（§3）。

2.5. **先行权。**
- 比赛的第一局以抽签决定——掷硬币、比点数最小的牌，方式不限。
- 之后的每一局由**上一局的胜者**先行（§10.4）。
- 若上一局以**平局**告终，则没有胜者，双方简单**互换**：上一局后行的一方本局先行。

> 据推测先手玩家的位置略弱：他在先行之前就公开手牌，却对对手的手牌一无所知。因此先行权
> 交给胜者。如果对局统计显示相反——先手玩家赢得更多——规则将改为「上一局的败者先行」。

## 3. 公开手牌——关键特色

3.1. 游戏**明牌进行**：双方的牌正面朝上，人人可见。

3.2. **唯一的例外是最初的第一着。** 先手玩家自取牌起即已公开（§2.4），也就是在其第一着
**之前**。后手玩家在先手的一着结束之前保持手牌扣合。

3.3. 先手玩家的一着一旦结束——**无论以何种方式**：打出根牌、摸了牌、让过行棋权——后手
玩家即公开手牌。

3.4. 此后直至本局结束，双方手牌均公开。§3.2 的不对称**每局只出现一次**，作为对先行权的
补偿。

3.5. **牌堆始终扣合**，背面朝上。这是有意为之：手牌像国际象棋那样公开，牌堆是游戏中唯一
的运气来源。牌堆的组成可以推算（28 减去所有可见的牌），但牌的顺序未知。

## 4. 主要规则：必须出牌

4.1. 轮到的玩家**只要能出就必须出**。该规则贯穿整局——寻找根牌的阶段和其后都适用。

4.2. 能出牌时不得跳过。能出牌时也不得从牌堆摸牌。

4.3. 推论：
- 手中有对子而根牌尚未打出 → 玩家必须打出根牌（§5.2）；
- 寻根阶段摸到对子 → 必须将其打出（§5.3）；
- 摸到能出的牌 → 必须用它出牌（§8.2）；
- 唯一可行的一着对自己不利 → 仍然必须走。§11.1 的陷阱正是建立在这一点上。

## 5. 一局的开始：寻找根牌

5.1. 每局总是以对子开始——**任意**对子。它成为根牌。

5.2. 轮到的玩家若手中有对子，必须将其作为根牌打出（§4.1）。若有多张对子，则由玩家自行
选择哪张作根牌。

5.3. 若没有对子——玩家从牌堆摸一张牌（§8）。
- 摸到对子 → 必须将其作为根牌打出。
- 摸到的不是对子 → 收入手中并让出行棋权。

5.4. §5.2–5.3 的循环轮流进行，直到有人打出根牌。

5.5. 这里不可能出现死局：一套牌中有 7 张对子，若牌堆已空，所有对子必然都在玩家手中。

## 6. 根牌打出之后的行棋

6.1. 玩家必须打出与某个开放端点数相同的牌（§4.1）。

6.2. **根牌只向一个方向发展。** 根牌的左端是死路，不能向那边发展。根牌的上方和下方也
不长枝。实际上根牌只提供**一个**开放端。

```
死路 ←── [4|4] ──→ 开放端「4」
```

6.3. 普通（非对子）牌以**直放**或**转向**方式打出。

**直放**——牌沿同一方向延续该枝。接上的一半封掉旧端，空余的一半成为新端。开放端的数量
不变：

```
原来：  … ── [3|5] ──→ 端「5」
之后：  … ── [3|5] ── [5|4] ──→ 端「4」
```

**转向**——牌接在枝的空余端上，但旋转了 90°。由此形成**分叉**——两个点数**不同**的空余
方向：

- **直向端**——被接牌的那个点数（例中为「5」）；它仍然存活，枝的方向不变；
- **转向端**——所接牌的空余一半（例中为「4」）；这条枝与直向方向成 90°。

```
原来：   … ── [3|5] ──→ 端「5」

之后：   … ── [3|5] ──→ 直向端「5」
                   │
                  [5]
                  [4]
                   ↓
              转向端「4」
```

*转向并不吃掉旧端，而是**增加**一个新端：开放端的数量加 1。*

**转向的牌如何摆在桌上。** 物理上有两种拼接方式：让接上的一半顺着直枝的走向，或者立刻
偏向一侧。这对规则没有影响——两种摆法得到的都是同样的两个端：直向端和转向端。请按桌面
空间选择，让各枝互不妨碍。

![转向的牌 6:1 与牌列齐平拼接](img/turn-inline.jpg)

*方式一：6:1 与牌列齐平拼接——它的「6」一半顺着直枝的走向。*

![同一张 6:1 向下错开、从侧面拼接](img/turn-sideways.jpg)

*方式二：同一张 6:1 向下错开、直接从侧面拼接。着法相同、端也相同——只是桌面摆法不同。*

两张照片上方都还能看到一个**封闭端**：竖枝顶在一张横放于其上的对子 1:1 上（§7.1）。

6.4. **新端限制。** 接到分叉任一端——无论直向端还是转向端——的第一张牌，**只能「直放」**。
它既不能形成新的转向，也不能用横放的对子封住该端。

换句话说：**转向之后立刻再转向是禁止的**，**刚刚形成的端也不能封**。

该限制对每个端各自独立生效，只要该端接上了哪怕一张牌即告解除。此后该端重新开放转向与
封枝。

*示例。* 一个分叉有端「5」（直向）和「4」（转向）。不能将 4:1 转向打出，不能将 5:6 转向
打出，也不能用对子封「5」或「4」。可以比如将 5:6 直放——此后由「5」长出的端重新对任何
着法开放，而端「4」仍是新端。

6.5. 除 §6.4 的情形外，**任何**一着都可以转向。

6.6. **唯一的例外是从根牌起的第一着。** 根牌之后的第一张牌可以转向打出，尽管根牌的端同样
是「新」的。这是权利，不是义务。

## 7. 对子与封枝

7.1. 对子是特殊的牌。它**只能以两种方式**打出：

- **直放**——对子像普通牌一样**顺着**枝摆放；该端保持开放并保留**同一**点数：

```
… ── [3|5] ── [5|5] ──→ 端「5」
```

- **横放**——对子**横跨枝的方向**摆放，该枝被**封住**，不能再发展：

```
                ┌───┐
                │ 5 │
… ── [3|5] ─────┤   │   ✕ 枝已封闭
                │ 5 │
                └───┘
```

封枝的实例见 §6.3 的照片：上方的竖枝顶在一张横放于其上的对子 1:1 上。

7.2. **对子不能「转向」打出。** 用对子做不出分叉。

7.3. 只能用**对应的**对子封端——即点数与该端点数相同的那张。

7.4. 新端不能封（§6.4）。作为第一张牌接到这种端上的对子只能**直放**。

## 8. 从牌堆摸牌

8.1. 每一着玩家从牌堆**至多摸一张**牌——寻根阶段与主阶段皆然。

8.2. 玩家只有在无牌可出时才摸牌（§4.1）。之后：
- 摸到的牌能出 → 玩家必须出牌，一着结束；
- 摸到的牌帮不上忙 → 玩家将其收入手中，什么也不摆，让出行棋权。

8.3. 若牌堆已空且无牌可出——玩家什么也不做，让出行棋权。

## 9. 一局的结束

一局因两种原因之一结束。

9.1. **僵局**——任何人都无法出牌：每个开放端要么已封（§7.1），要么已死（所需的牌既不在
手中也不在牌堆——带该点数的 7 张牌已全部在桌上）。特殊情形：所有端无一例外全部封闭。

9.2. **出完**——玩家打出手中最后一张牌。其手中一无所剩。

9.3. 僵局时不再从牌堆补牌——立即计分（§10）。

## 10. 计分与比赛胜负

10.1. 一局结束后，每名玩家计算**自己剩余手牌的点数总和**——所有牌两半点数之和。出完的
玩家（§9.2）总和为零。

10.2. **对子 0:0 的特殊价值。** 若 0:0 是玩家手中**唯一**剩下的牌，它计 **25 分**。若手中
还有至少一张其他牌，0:0 照常计 **0** 分。

10.3. **只有总和严格更小的一方不记分。** 其余玩家将自己的总和加到累计分上。双人对局中这
意味着：
- 总和不同 → 较大的一方把自己的总和加给自己，较小的一方什么也不得；
- 总和**相等** → **双方**都加。

10.4. **本局胜者**是总和严格更小的玩家，即未得分的一方。总和相等时本局无胜者。胜者在
下一局先行（§2.5）。

10.5. **比赛的结束。** 一旦计分后至少一名玩家达到 **100 分或以上**，比赛即告结束。
**累计分更多者输。** 若累计分相等（例如 103 比 103）——**平局**，比赛无胜者。

## 11. 规则变体

11.1. **「对子只能封枝」。** 对子不能直放——它只能封枝（横放）。由此自动得出：对子不能
作为新端上的第一张牌，因为那里不允许封枝（§6.4），而在此变体中对子没有其他选择。

**这是规则的最初版本**——游戏最初正是这样构想的。对子直放是同一天晚上、在最初几局的
过程中出现的（§14）。

该变体带来一个**陷阱**：对子不再是安全的牌，可以迫使对手在对其不利的时刻封掉这一局。
示例：根牌 2:2，后手玩家将 2:1 直放。若先手手中只有一张 1:1，他必须出牌（§4.1），而这
张牌只能横放——也就是封掉唯一的端、斩断本局，哪怕他手里的分数还很多。

目前以 §7.1 的版本为主：对子既能延伸也能封枝。它更温和、给出更多抉择，但去掉了此变体
的陷阱——因此两种都值得一试。

12.1. **3 人及以上模式。** 待双人游戏实现之后再议。
（28 张牌：三人各 7 张 → 牌堆 7 张；四人各 7 张 → 牌堆 0 张。）

## 13. 关于平衡的札记

*这些不是规则，而是机制的推论——记录下来，免得每次重新推导。*

13.1. **端的收支。** 直放 → 端数不变；转向 → +1；对子横放封枝 → −1。一局从一个端开始
（§6.2）。

13.2. **僵局可以来得很快。** 最短的一局：根牌 → 一张牌直放 → 对子横放。桌上三张牌，双方
手中几乎都是满手牌。这正是总和较小一方的速胜。

13.3. **对抗快封的手段是转向。** 它随时可用：任何合适的非对子牌都可以转向打出，且 §6.4
禁止对手立即封新端。于是手牌重的玩家用转向拖长本局，手牌轻的玩家用封枝扼杀它。一局的
长短是双方直接争夺的对象，也是这款游戏的核心冲突。就最初的实战对局而言，机制感觉是平衡
的；最终将由扩大测试来检验。

13.4. **转向的上限。** 要让端数变为 0，封枝必须比转向多一次。对子共 7 张，一张作了根牌 →
封枝至多 6 次 → 每局转向不超过 5 次。若转向已达 **6 次或更多，靠封尽所有端制造僵局已不再
可能**——本局只能以出完或死端告终。每一张直放的对子都把上限再降低 1。

13.5. **对子直放会不可逆地烧掉钥匙。** 同样的对子没有第二张，因此从此以后任何带该点数的
端都再也无法封住——只能靠耗尽同点牌把它闷死。

13.6. **通往零的两条路。** 出完（§9.2）保证总和为 0，即必然严格更小——永远不会得分。
因此玩家有两套不同的计划：手牌更轻时做僵局，或者把手牌全部出光。转向服务于第二套计划，
封枝服务于第一套。

13.7. **为什么 0:0 值 25 分（§10.2）。** 没有这条规则，0:0 会是理想的「压箱牌」：可以免费
留到最后，而只剩一张 0:0 的玩家总和为 0——即便对手出完他也不用付分（0 比 0 是平，双方各
付零分）。这条规则把局面倒转过来：留到最后的 0:0 成为整套牌中最昂贵的一张。

13.8. **平局惩罚双方。** 总和相等时双方都付分（§10.3），因此只有严格更小的总和才安全。
再加上败方加上的是自己的**全部**总和而非差额，这让终盘变得凌厉：41 比 40——一分之差价值
41 分。

13.9. **比赛短是正常的。** 一套牌平均每张 6 分，7 张的满手约 42 分。快速僵局（§13.2）几乎
把全部手牌留在手上，也就是说这样一局就让败方立得 40–50 分，打到 100 的比赛 2–3 局便告
结束。这一点照单全收：比赛的长度不是常数，而是搏斗的结果。处于劣势的玩家自己就有动力
分叉拖局，好多出些牌；比赛是短是长，正取决于他做得如何。

13.10. **先行权——加速器还是追赶机制。** 先行权交给胜者（§2.5）。如果先手玩家的位置确实
更弱，这就是追赶机制，能拉平比赛。如果先行反而是优势，这条规则就会加大领先者的差距。
这正是统计数据要回答的问题。

13.11. **公开手牌 + 强制出牌 = 完全信息游戏。** 玩家的决策归结为在可出的牌中选择哪一张
以及如何摆放。运气只剩在扣合的牌堆里（§3.5）。

## 14. 游戏的由来

这款游戏是我在 2026 年 7 月 31 日晚上为我心爱的妻子奥莱奇卡（Olechka，Olga 的爱称）想出
来的。

我不喜欢普通多米诺对运气的依赖程度：胜负太经常不取决于玩家的选择，而取决于来了哪张牌。
可我也不想把运气完全去掉——没有它，那份兴味就没了。规则的关键特色由此而来：手牌像棋盘
上的棋子一样摊开，唯一的运气来源是扣合的牌堆（§3.5）。

想法我很快就勾勒了出来，我们随即坐下来玩，玩了一整晚。我最初的版本更严：对子只允许横放，
也就是说它总是封枝（§11.1）。奥莱奇卡提议也允许直放——这样玩家有了选择，这条规则便成了
主规则（§7.1）。

我们都喜欢这款游戏，所以我把规则记了下来。
